# 🎙️ Whisper Speech Recognition App

A simple Streamlit web app for real-time speech-to-text transcription using OpenAI's Whisper model.  
Supports both audio file uploads and live microphone recording.

---

## 🚀 Features

- 🎤 Record speech directly from your microphone
- 📁 Upload `.wav` or `.mp3` audio files
- 🔍 Choose from multiple Whisper model sizes (`tiny`, `base`, `small`, `medium`, `large`)
- 🌐 Optional language specification (e.g., `en`, `fr`, `hi`)
